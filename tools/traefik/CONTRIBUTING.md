Thank you for considering contributing to this project.

Guidelines
- Sanitize any example values before submitting a PR (no real IPs, tokens, or credentials).
- Keep changes minimal and focused; document behavior changes in the PR description.
- Run `shellcheck` on `import.sh` and fix obvious issues before opening a PR.

Reporting issues
- Open an issue describing the bug or enhancement with steps to reproduce and relevant logs.

Security
- Do not include secrets, tokens, or private network IPs in issues or PRs. If you need to share sensitive information for debugging, use a secure channel.
